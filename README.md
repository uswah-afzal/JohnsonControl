# Johnson Controls - Redesign & Interactive Platform

A modern, high-performance website redesign for **Johnson Controls** built with **Next.js**, **React**, and **Tailwind CSS**.

## Features

- **Hero & Dynamic Performance Showcase**: Interactive performance progress switcher and stats counter.
- **OpenBlue™ & Net-Zero Stacked Cards**: Sticky stacked cards scroll architecture for OpenBlue platform & DEWA HQ customer story.
- **Single-Card Smooth Scroll Carousel**: Interactive News and Building Insights section.
- **Compact & Modern Design**: Clean glassmorphism cards, responsive navigation, and brand-authentic SVG elements.
- **Equal Brand Social Icons**: Custom borderless SVG social icons with official brand hover color transitions.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **UI & Styling**: React 19, Tailwind CSS, Lucide Icons
- **Animation & FX**: CSS Glassmorphism, Smooth Scroll Sticky Cards, IntersectionObserver

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build for Production

```bash
npm run build
```
